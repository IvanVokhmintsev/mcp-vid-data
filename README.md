# MCP:RSV Data

[![Опубликовано на Infostart](assets/infostart-logo.png)](https://infostart.ru/1c/tools/2720241/)

Опубликовано на Infostart: <https://infostart.ru/1c/tools/2720241/>

**Бесплатный MCP-сервер для рабочей базы 1С:Предприятие** — два направления в одном расширении:

- **Данные базы — простым языком, без языка запросов 1С.** ИИ-агент (Claude, Cursor и др.) по обычной
  просьбе («покажи остатки по складам», «найди контрагента», «сколько продали такого-то товара»)
  получает реальные данные из базы — польза бухгалтеру и аналитику. Только чтение, права пользователя
  соблюдаются, персональные данные обезличиваются автоматически.
- **Структура метаданных любой конфигурации.** Точные имена таблиц, полей и типов — удобный контекст
  для разработчика и его ИИ-агента, чтобы он не выдумывал имена.

Работает на **любой конфигурации** (УТ, ERP, БП, самописная), реализован как расширение конфигурации
1С — базу не меняет.

> Нужно больше по данным — готовые отчёты конфигурации, регламентированная отчётность, дашборды по
> базе, изменение данных — это платное развитие того же продукта:
> **[MCP:RSV Data Pro](https://prepod2003.github.io/rsv-data-pro/)**.

> Это про **данные**. Если нужна **разработка** в 1С:EDT (создание и редактирование кода, метаданных,
> форм, СКД, отладка) — это другой, **платный** продукт линейки RSV:
> **[MCP:RSV Server](https://prepod2003.github.io/edt-ai-1c/)**.

## Быстрый старт

1. **Установить расширение в базу.** В 1С:Предприятии: функции технического специалиста →
   «Управление расширениями конфигурации» → «Добавить» → выберите `RSVData.cfe` → перезапустите
   программу. (Или из Конфигуратора: Конфигурация → Расширения → загрузить из файла → обновить
   конфигурацию базы F7.)
2. **Подключить ИИ-клиент** — двумя способами (оба через HTTP, без STDIO):
   - **Напрямую к HTTP-сервису 1С** — клиент ходит в опубликованную базу сам; прокси не нужен.
   - **Через HTTP-прокси** — `rsvdata-bridge` (удобнее всего Docker на Linux) держит логин/пароль
     у себя; в конфиг клиента попадает только URL прокси.
3. Запустите мастер (`rsvdata-bridge setup` или контейнер с TTY), выберите способ, укажите
   параметры и клиент — мастер проверит связь и выдаст готовый блок `.mcp.json`.

Подробно (оба способа, примеры конфигов для Claude Code / Cursor / Cline, диагностика) —
в [`guide.md`](guide.md).

## Инструменты

`config` (паспорт базы) · `describe` (что есть в базе) · `get_structure` (полная структура объекта) ·
`query` (чтение данных без языка запросов) · `execute_query` (готовый запрос 1С) · `ping` · `help`.

Описание каждого — в [`guide.md`](guide.md), а также внутри самого сервера: `help` без параметров —
обзор, `help topic=<инструмент>` — подробности.

## ⭐ Больше по данным — MCP:RSV Data Pro (платный)

MCP:RSV Data читает данные и структуру базы. Платное развитие того же продукта — **MCP:RSV Data Pro**:

- **готовые отчёты конфигурации** — те же, что человек открывает в разделах 1С, поэтому цифры
  совпадают с тем, что показывает сама 1С;
- **регламентированная отчётность** — показатели сохранённых деклараций и расчётов (НДС, прибыль,
  УСН, 6-НДФЛ, взносы, баланс);
- **дашборды по базе** — продажи, деньги, склад на одной странице; страницу открывают и без
  ИИ-агента;
- **изменение данных** — по адресным правам и только после подтверждения;
- **все базы компьютера через один адрес** — число баз не ограничено и не тарифицируется.

### 👉 MCP:RSV Data Pro — [prepod2003.github.io/rsv-data-pro](https://prepod2003.github.io/rsv-data-pro/)

14 дней бесплатно — по кнопке в 1С, без регистрации и платёжных данных.

## 🔧 Разработка в 1С:EDT — MCP:RSV Server (платный)

MCP:RSV Data **читает** данные. Если нужно **разрабатывать** в 1С:EDT — создавать и править BSL-код,
объекты метаданных, формы, отчёты СКД, отлаживать — для этого есть профессиональный продукт линейки RSV:

### 👉 MCP:RSV Server — [prepod2003.github.io/edt-ai-1c](https://prepod2003.github.io/edt-ai-1c/)

Кстати: само расширение MCP:RSV Data **от начала до конца создано ИИ-агентом именно через MCP:RSV
Server** — создание расширения и его объектов (HTTP-сервис, общие модули), написание всего кода и его
проверка через код-ревью. Человек-программист не написал вручную ни строки. То есть сложную разработку
в 1С сегодня реально вести полностью силами ИИ (подробнее — раздел P.S. в [`guide.md`](guide.md)).
